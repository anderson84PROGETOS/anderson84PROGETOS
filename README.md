# Meu Projeto - Scripts Python para Segurança e Automação

Olá, sou o **Anderson**, criador de diversos scripts Python voltados para a automação e segurança na web. Esse repositório contém uma coleção de meus projetos e ferramentas criadas para facilitar tarefas de pentesting, enumeração de redes, coleta de informações, entre outras funcionalidades voltadas para a área de segurança da informação.

## Projetos Incluídos

- **Scanner de DNS**: Ferramenta para realizar enumeração de registros DNS, incluindo registros MX, IPs e transferências de zona.
- **Web Scraping**: Scripts para extrair URLs, emails e outras informações de websites com o uso de BeautifulSoup e Requests.
- **Captura de Pacotes ARP**: Ferramenta para capturar pacotes ARP e identificar dispositivos na rede.
- **Consultas WHOIS**: Scripts para consultar informações WHOIS de domínios e IPs.
- **Exploração de Vulnerabilidades**: Ferramentas baseadas no Nmap para busca de CVEs e análise de banners de serviços.

## Requisitos

- Python 3.x
- Bibliotecas necessárias (instale usando `pip`):
  - requests
  - beautifulsoup4
  - nmap
  - dns.resolver
  - mac_vendor_lookup
  - other dependencies
