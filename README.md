## Projetos Desenvolvidos

Aqui estão alguns dos projetos que desenvolvi:

### 1. **Website Information Scraper**
- **Descrição:** Script Python para capturar informações de websites, como cabeçalhos HTTP, URLs e emails encontrados nas páginas.
- **Ferramentas Usadas:** `requests`, `BeautifulSoup`, `re`, `tkinter`.

### 2. **DNS Bruter**
- **Descrição:** Script para realizar enumeração de registros DNS e realizar transferências de zona.
- **Ferramentas Usadas:** `dnspython`, `socket`, `requests`.

### 3. **ARP Scanner**
- **Descrição:** Ferramenta para escanear a tabela ARP de dispositivos conectados na rede.
- **Ferramentas Usadas:** `scapy`, `os`, `socket`.

### 4. **CVE Searcher**
- **Descrição:** Script para buscar CVEs (Common Vulnerabilities and Exposures) de 2000 a 2024.
- **Ferramentas Usadas:** `requests`, `BeautifulSoup`.

### 5. **Subdomain Finder**
- **Descrição:** Ferramenta para buscar subdomínios de um site usando brute force e dicionários de subdomínios comuns.
- **Ferramentas Usadas:** `requests`, `socket`, `dns.resolver`.
